# Features

## Backend
- Signup, Login, Logout APIs
- JWT-based authentication
- Password hashing with `Bcrypt`
- Connected to MongoDB using `Mongoose`
- Profile photo upload with `Cloudinary`
- File handling with `Multer`
- Input validation (email & password) using `validator`

## Frontend
- Signup, Login, Logout pages
- Redux Store setup for:
  - User session data
  - Dynamic table data
- Create Table UI
  - Add fields dynamically
  - Update field names and types
- Add data rows dynamically
- Integrated toast notifications with `react-hot-toast`
- Icons added via `lucide-react`


# Tech Stack used

## Backend
- Express
- MongoDB 
- Mongoose : to connect with DB
- jsonwebtoken : for authentication and session maintaince
- bcrypt : for secure password storage
- dotenv : to store data securely
- validator : to validate email_id and password
- multer : to recieve files from frontend
- cloudinary: to store images



## Frontend
- React
- Tailwind 
- Daisy UI
- Redux store : for state management
- react-hot-toast : to create toast messages
- Lucide react : for Icons
